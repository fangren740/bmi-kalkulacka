# RychléVýpočty.cz V7 — MAIN PAGES DESIGN UPGRADE HANDOFF (FINAL HOMEPAGE)

## Stav
Homepage prošla design discovery, několika rebuilty a finálním release auditem. **Homepage design je po úspěšném live smoke testu určen k INDEX LOCK.**

## Zamknutá designová DNA
- bright future-tech / precision / positivity / simplicity
- primární art-direction reference: Zaplytic (Land-book), nikoli 1:1 kopie
- RV navy / blue / electric green
- velká typografie, whitespace, branded doodles / hand-drawn tahy
- blesk / diagonála / jemný technický grid jako vlastní identita
- silné grafiky / branded covers; žádné generické stock náhledy
- dark bloky pouze jako kontrastní stage moments, ne depresivní dark mode
- běžný uživatel musí vše pochopit bez nerd / dashboard bariéry

## Homepage bloky — LOCK pokud live QA projde
Hero → search → product canvas → quick entry → situation stories → thematic areas → all calculators CTA → editorial guides → methodology/trust/disclaimer → premium footer.

## Footer standard
Brand + social, Rychlé vstupy, Hlavní oblasti, Informace, legal row. Povinné dostupné stránky: Jak počítáme, Data a benchmarky, Redakční zásady, Podmínky používání, Ochrana osobních údajů, Cookies, Kontakt.

## Co NEdělat
- nevracet generic SaaS
- nevyrábět box-in-box hero
- nepřidávat sekce jen pro zaplnění
- nerozkopávat homepage bez dat / jasného problému
- neměnit design samotných kalkulaček v rámci tohoto main-pages wave

## Další pořadí práce
1. `kalkulacky.html` — premium discovery/catalog page
2. 1× reprezentativní hub (Finance doporučeno)
3. 1× article/guide template
4. QA jako systém vedle současných kalkulaček
5. rollout na ostatní huby / články

## Technický standard pro další stránky
- mobile-first, bez horizontálního overflow
- touch targets cca 44 px
- performance-safe bez zbytečných frameworků / webfontů
- reálné brand assety
- search / interní navigace podle účelu stránky
- trust/disclaimer podle rizikovosti tématu
- před release: link audit, SVG ref audit, SEO/indexability audit, mobile QA, live PSI po deployi

## Zdroj pravdy
Při navazování vždy načti nejnovější produkční ZIP/repo a tento handoff. Homepage po locku používej jako design reference pro shell, ne jako šablonu, kterou mechanicky kopíruješ na každý typ stránky.
